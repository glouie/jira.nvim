# TUI Glossary

Use these definitions to keep specs and reviews consistent.

| Term | Meaning |
|---|---|
| `Affordance` | A cue that indicates an element can be interacted with. |
| `Anchor` | Stable reference point in layout or navigation. |
| `Async state` | State while background work is running. |
| `Breadcrumb` | Path showing current location in hierarchy. |
| `Command palette` | Searchable launcher for actions. |
| `Context` | Current scope such as project, issue, or environment. |
| `Density` | Amount of information per visible area. |
| `Destructive action` | Action that deletes or irreversibly changes data. |
| `Detail pane` | Region that shows expanded info for selected item. |
| `Disabled state` | Visible but intentionally non-interactive control. |
| `Discoverability` | How easily users can find features/actions. |
| `Empty state` | UI shown when no records are available. |
| `Error state` | UI shown when an operation fails. |
| `Focus` | Element currently receiving keyboard input. |
| `Focus trap` | Modal behavior that keeps focus inside overlay. |
| `Hierarchy` | Priority ordering of information and actions. |
| `Hotkey` | Keyboard shortcut for an action. |
| `Inline validation` | Validation feedback at the field level while editing. |
| `Information scent` | Cues that suggest where content/actions are located. |
| `Intent` | Semantic priority of action: primary, secondary, destructive. |
| `Loading state` | Temporary state while data is being fetched. |
| `Modal` | Blocking overlay requiring user action. |
| `Navigation model` | Rules for moving between pages/regions/items. |
| `Pagination` | Dividing result sets into pages/chunks. |
| `Pane` | Bounded layout region in a split interface. |
| `Progressive disclosure` | Revealing complexity only when needed. |
| `Ready state` | Fully loaded and interactive state. |
| `Retry path` | Explicit recovery action after failure. |
| `Secondary action` | Useful but lower-priority action. |
| `Selection` | Currently highlighted item in list/tree/table. |
| `Skeleton` | Placeholder layout while data loads. |
| `State model` | Allowed states and transitions for UI element/page. |
| `Status bar` | Persistent bottom strip with mode and status text. |
| `Telemetry` | Event instrumentation for usage/error metrics. |
| `Toast` | Temporary non-blocking status message. |
| `Viewport` | Currently visible portion of scrollable content. |
| `Workflow` | Ordered task steps to reach user goal. |
