# UI Element Template

Use this template when adding a new element entry to `UI_ELEMENTS.md`.

- `Element ID`: `cmp_<name>`
- `Purpose`: one sentence
- `Anatomy`: required visible parts
- `States`: allowed states
- `Keyboard contract`: required keys/behaviors
- `Error behavior`: recoverable failure path
- `Accessibility notes`: labels, focus, non-color signals
