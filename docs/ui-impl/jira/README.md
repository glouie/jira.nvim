# Jira.nvim UI Mapping

This folder contains Jira.nvim-specific mapping built on top of:

- portable TUI contracts in `docs/tui`
- Neovim implementation profile in `docs/ui-impl/NEOVIM_LUA_PROFILE.md`

Files:

- `JIRA_SURFACE_MAP.md`: Jira surface and key behavior contracts
- `JIRA_ACCEPTANCE_CHECKLIST.md`: manual regression checklist
